# Заказы МИМ → Telegram

Сайт остаётся на GitHub Pages. `worker.mjs` принимает заказ и отправляет его в группу сотрудников через Telegram. Токен и ID группы хранятся только в секретах Cloudflare. Секретов в исходниках нет.

Корзина пока выключена в `scripts/order-config.js`: её нужно включить после настройки и проверки настоящего получателя. Тесты используют имитацию Telegram, реальных сообщений не отправляют.

## Подключение

1. Создайте аккаунт Cloudflare и войдите. В корне репозитория выполните `npx wrangler@4 login`.
2. Перевыпустите присланный в переписку токен через `/revoke` в BotFather. Новый токен не отправляйте в чат и не сохраняйте в Git.
3. Добавьте бота в группу сотрудников; он должен иметь право отправлять сообщения. Отправьте `/start@имя_бота` в группе.
4. Чтобы узнать chat_id, выполните `python3 server/find-telegram-group.py`. Токен вводится скрыто, не сохраняется. Скрипт выводит только названия и ID групп из последних обновлений, не содержимое сообщений. Если у бота уже есть webhook, он останется неизменённым.
5. Разверните обработчик из корня репозитория:

   ```sh
   npx wrangler@4 deploy --config server/wrangler.jsonc
   npx wrangler@4 secret put TELEGRAM_BOT_TOKEN --config server/wrangler.jsonc
   npx wrangler@4 secret put TELEGRAM_CHAT_ID --config server/wrangler.jsonc
   ```

   В интерактивные запросы введите новый токен и chat_id группы. Не добавляйте значения в командную строку. Пока секреты не настроены, сервер возвращает 503 и ничего не отправляет.
6. Скопируйте адрес опубликованного Worker и добавьте `/orders`. Укажите его в `scripts/order-config.js`, установите `enabled: true`.
7. В CSP в `index.html` добавьте **только origin этого Worker** в `connect-src`, например `connect-src 'self' https://mim-orders.example.workers.dev`. Не добавляйте Telegram в CSP и не передавайте токен браузеру. Если используется другой домен сайта, добавьте его в `ALLOWED_ORIGINS` и повторно разверните Worker.
8. Обновите версии ссылок на `cart.js`, `order-config.js`, `catalog.js` и стили при изменении этих файлов. До публикации сайта отправьте один явно помеченный тестовый заказ на настроенный обработчик и убедитесь, что он пришёл в правильную группу.
9. Опубликуйте изменения сайта в GitHub Pages. Проверьте оформление с телефона и реальное получение в группе.

## Проверки

```sh
node --test tests/orders.test.mjs
npx wrangler@4 deploy --dry-run --config server/wrangler.jsonc --outdir /tmp/mim-orders-build
```

Сервер заново считает сумму по `scripts/catalog.js`, проверяет номер, ID блюд, варианты и количество. Цены клиента не используются. При изменении меню синхронизируйте `index.html` и `scripts/catalog.js`, поменяйте `catalogVersion` и версии файлов, разверните Worker и сайт. Тест проверяет соответствие каталога карточкам.

Лимиты: 20 строк, 20 единиц в строке, 100 единиц в заказе; комментарий 300 символов. В заказах с галушками передаётся выбранный вид. Телефон — российский номер +7. Оплата и стоимость доставки не включены; сотрудник подтверждает состав и получение по телефону.

Браузер хранит только корзину, без телефона и комментария. На сервере хранятся хеш и состояние отправки 48 часов, без телефона и состава. После успешного `sendMessage` заказ считается отправленным, но не подтверждённым кафе. Если Telegram ответил явной ошибкой, повтор разрешён. При тайм-ауте отправка считается неопределённой, повтор для того же ID не создаёт второе сообщение: нужно свериться с группой по телефону клиента. Для повторных попыток без перезагрузки страницы используется тот же UUID. Сознательная новая отправка с новым UUID считается новым заказом.

Ограничитель запросов работает по IP (5 попыток в минуту в пределах узла Cloudflare); общая сеть может делить лимит. CORS не является авторизацией. Для публичного запуска при появлении спама можно дополнительно подключить Turnstile.

Документация: [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages), [секреты Workers](https://developers.cloudflare.com/workers/configuration/secrets/), [Telegram sendMessage](https://core.telegram.org/bots/api#sendmessage).
